# Photographs

Put your original, approved-for-publication photographs here. Use short lowercase names, such as `canberra-evening.webp`.

Prefer WebP or JPEG at about 1600–2400 pixels on the long edge. Keep a separate high-resolution original elsewhere. Remove GPS/location metadata before publishing. Do not upload private files or other people's images without permission.

The site does not currently contain real photographs. CSS drawings are clearly labelled placeholders. See the repository README for the image markup and gallery viewer.
